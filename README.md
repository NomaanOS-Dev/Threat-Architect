# 🛡️ Threat-Architect

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://threat-architect.streamlit.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An **AI-Powered Defensive Threat Modeling & MITRE ATT&CK Mapping Platform** engineered for automated attack surface assessment.

## 🌟 Key Capabilities
* **Threat Modeling:** Mapped to **MITRE ATT&CK** & **NIST SP 800-53**.
* **AI Triage Engine:** Utilizes **LangChain** and OpenAI .
* **Incident Reports:** One-click download in Markdown & Text.

Developed as part of the **Sovereign AI Stack (SAS)** research initiative at **IHFC — IIT Delhi**.
